The ordinary C overlay and its full-frame contract use a 640 × 480 uint16 source, signed coordinates and an in-place destination. The short-tail test specializes the C contract to 353 queries. Both configurations use 256-slot physical tiles.

The frozen camera inputs in `remap_inputs.npz` derive from the OpenCV calibration samples at commit `49486f61fb25722cbcf586b7f4320921d46fb38e`. Seven views were used for calibration. The two held-out grayscale images (left12 and left14) were widened to uint16 by multiplication by 257. The short-tail fixture replaces the first seven source pixels and supplies deterministic coordinates, enable flags and initial destination values. The long test uses the original integer maps and enables the first 16 valid tiles. Use NumPy's `load(..., allow_pickle=False)` to read the array archive, SHA-256 `10e764be30c2f6dadda5696fae2513e7a43657186feaf91c2ce6a371e1df9023`. See [OpenCV calibration samples](https://github.com/opencv/opencv/tree/49486f61fb25722cbcf586b7f4320921d46fb38e/samples/data) and [the supplied Apache License 2.0](OPENCV_LICENSE).
